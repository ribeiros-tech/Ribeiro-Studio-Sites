# Ribeiro Studio

Repositório destinado aos projetos de websites desenvolvidos pelo **Ribeiro Studio**, reunindo experiências, estudos e projetos de desenvolvimento web.

## Projetos

### Landing Page

Landing page desenvolvida com foco em apresentação visual, estrutura objetiva e experiência responsiva.

**Tecnologias:** HTML5, CSS3 e JavaScript.

### Site Profissional

Website profissional desenvolvido com foco em uma apresentação moderna, organizada e responsiva para negócios e serviços.

**Tecnologias:** HTML5, CSS3 e JavaScript.

### Site Premium

Website premium desenvolvido com uma proposta mais sofisticada de design, experiência do usuário, interações e apresentação visual.

**Tecnologias:** HTML5, CSS3 e JavaScript.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Design Responsivo
- UI/UX
- Motion Design

## Objetivo

Este repositório reúne projetos desenvolvidos como parte da evolução prática em **desenvolvimento web, UI/UX e criação de experiências digitais**.

Novos projetos serão adicionados conforme o portfólio evoluir.
